# EV default weapon imports

These are ev.io source assets, not original KRYX designs. Source URLs are recorded in sources.json. Imported using Blender 4.5, with uniform per-weapon fitting and corrected grip contacts; source geometry and texture UVs are retained. Color factors are converted from sRGB to linear for glTF.

Rebuild with tools/blender/import_ev_defaults.py. Editable Blender files are in this directory. The game uses these firearms through BlenderArsenal.js; its existing sword remains active. The imported sword and inactive sniper are available for model review.
