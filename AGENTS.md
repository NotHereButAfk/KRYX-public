# KRYX contributor instructions


## Game update announcements

Copilot is assigned Release Notes Editor (documentation role). For every game update, dispatch a bounded note-writing proposal when eligible, review it, and update release/game-update.json with a new immutable id and concise verified player-facing changes. Follow docs/studio/DISCORD-UPDATES.md. If the worker is unavailable, complete reviewed notes locally and report the fallback. Never post credentials or internal links. The primary repo announces successful main push deployments automatically; the mirror does not send duplicates.
