Privacy policy

On kryx.live, account registration and login use our game server. We store your username, email address, password hash, game statistics, achievement progress, cosmetic rewards, and active login sessions to operate your account. Browser storage also holds settings and cached profile information.

Browser storage

Account passwords are stored on the server as salted scrypt hashes, not plaintext. Login uses an HttpOnly session cookie. Clearing browser storage does not delete your server account or its progress. Local development builds may use a separate browser-only demo account store.

When you request password recovery, the configured email provider processes your email address and a temporary four-digit code to deliver the message. Codes expire after ten minutes; the account database stores a keyed hash rather than the code itself. A successful password reset invalidates the code and your existing login sessions.

Skin purchases

For Solana skin purchases, the server stores your account ID, purchased item, payment currency and amount, order reference, quote, accepted terms version, timestamps, merchant address, and transaction signature. The blockchain transaction is public and may reveal the paying wallet address. We use a Solana RPC service to verify payment and Coinbase public market data to quote SOL prices. We do not request or store wallet private keys or recovery phrases. Purchase records remain on the server for delivery and support; clearing browser storage does not delete them.

Online matches

When you join an online match, the game server processes your session and gameplay state to run the match and record account progress.
